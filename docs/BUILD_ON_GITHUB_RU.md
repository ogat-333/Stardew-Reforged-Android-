# Сборка Stardew Reforged Android через GitHub (без компьютера)

Сборка запускается на серверах GitHub Actions. Компьютер или ноутбук не нужны.

## Что подготовить

Нужна ссылка на прямое скачивание **того же APK**, который проверен для этого проекта:
- размер: 430 623 152 байта;
- SHA-256: `b9ae4727e10a89b144a1301076ebb1e38586aba13f85c4c86ad9d5c3aaf21a28`.

Ссылка должна позволять серверу GitHub скачать файл без ручного подтверждения в браузере. Если облако требует Bearer-токен, его можно сохранить отдельным секретом. Не публикуйте APK в открытом доступе.

## Добавить ссылку как секрет GitHub

Откройте репозиторий на телефоне:
`https://github.com/ogat-333/Stardew-Reforged-Android-/settings/secrets/actions`

1. Нажмите **New repository secret**.
2. В поле **Name** укажите точно: `GAME_APK_URL`.
3. В поле **Secret** вставьте прямую ссылку для скачивания APK.
4. Нажмите **Add secret**.

Если облачный сервис требует Bearer-токен, повторите шаги и создайте секрет с именем `GAME_APK_BEARER_TOKEN`. Если токен не нужен, этот секрет создавать не надо.

## Запустить сборку

1. Откройте вкладку **Actions** репозитория.
2. Выберите **Build Reforged Android launcher**.
3. Нажмите **Run workflow**, затем подтвердите запуск.
4. Откройте появившийся запуск и дождитесь завершения всех шагов.
5. Если сборка завершилась успешно, скачайте артефакт **Stardew-Reforged-Android-launcher**.

## Что делает workflow

- скачивает APK по секретной ссылке и сверяет SHA-256;
- извлекает только три DLL, нужные для компиляции;
- использует их только на временном сервере GitHub Actions;
- не коммитит APK или игровые DLL в репозиторий и не включает их в артефакт;
- собирает Android ARM64 launcher APK.

Это пока сборка загрузчика, а не подтверждение запуска игры с модами. После сборки потребуется установить загрузчик и проверить его на Android 15.
